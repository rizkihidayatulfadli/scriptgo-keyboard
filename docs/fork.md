# Fork HeliBoard

Keyboard di `android/` adalah fork [HeliBoard](https://github.com/HeliBorg/HeliBoard) **v4.1** (GPL-3.0), diimpor sebagai git subtree dengan `--squash`.

## Update dari upstream

```bash
git remote add heliboard https://github.com/HeliBorg/HeliBoard.git   # sekali saja
git fetch heliboard tag <versi-baru> --no-tags
git subtree pull --prefix=android heliboard <versi-baru> --squash
```

Lalu build ulang dan tes di HP. Konflik biasanya hanya muncul di file yang ada di daftar di bawah.

Nama produk: **ScriptGo** (`id.scriptgo.keyboard`). Package Kotlin kode sendiri tetap `com.magickeyboard.*` (internal, tidak terlihat user). Saat merge update HeliBoard, konflik di ketiga string nama di atas cukup diselesaikan dengan tetap memakai "ScriptGo".

## Build

- CI (`.github/workflows/android.yml`) mem-build debug APK di setiap PR yang menyentuh `android/` atau `engine/`. APK bisa diunduh dari tab **Actions** → run terbaru → **Artifacts** → `magic-keyboard-debug-apk`.
- Build lokal butuh Android SDK dan NDK (versi di `app/build.gradle.kts`): `cd android && ./gradlew assembleDebug`.
