# Hapus Akun dan Data

Akun hanya dibuat jika kamu masuk untuk **sinkronisasi** (opsional). Tanpa akun, semua data hanya ada di HP atau browser kamu.

## Hapus dari aplikasi Android

1. Buka aplikasi, pilih tab **Akun**.
2. Ketuk **Hapus akun**, lalu **Hapus**.

Akun dan semua template, kontak, dan field yang tersimpan di server langsung dihapus permanen. Data di HP tetap ada; hapus lewat Pengaturan Android → Aplikasi → ScriptGo → Penyimpanan → Hapus data jika ingin menghapusnya juga.

## Minta penghapusan lewat email

Jika tidak bisa membuka aplikasi, kirim email ke **halo@scriptgo.id** dari alamat email akunmu dengan judul "Hapus akun". Akun dan semua datanya dihapus paling lambat 7 hari setelah permintaan diterima, dan kamu akan menerima konfirmasi.

## Data yang dihapus

| Data | Dihapus |
|---|---|
| Email akun | Ya |
| Template, kontak, dan field kustom di server | Ya |
| Data di HP atau browser | Tidak otomatis (hapus data aplikasi, atau keluar dari akun di extension) |

Tidak ada data yang disimpan lebih lama setelah akun dihapus, kecuali cadangan database server yang otomatis terhapus dalam 7 hari.
